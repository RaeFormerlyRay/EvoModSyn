# PatchMind Modular

A modular synthesizer that runs in the browser, with patch cables you can see, and an AI performer that designs patches and plays live sets. Everything runs on the Web Audio API with no build step and no dependencies.

## Run it

Open `index.html` through any static server, for example:

```
python3 -m http.server 8000
# then open http://localhost:8000
```

Press **Power on** (browsers only allow sound after a click), type an action such as "Design an acid bass patch" or "Play a full 15 minute acid live performance", set the performer's personality, and press **Perform**.

`python3 build.py` inlines everything into `dist/patchmind.html`, a single page that can be published as a Claude artifact.

## Modules

| Module | What it is |
|---|---|
| Pulse | Master clock with tempo and swing (CLK, BEAT, BAR outs) |
| Sequencer A / B | 16-step sequencers with 8 patterns (A–H) and a song mode that chains patterns with repeat counts. Per step: pitch, gate, accent, slide, probability and ratchets (1–4). Global: length, direction (fwd/rev/ping/random/drunk), clock divide, root, scale, octave, transpose, gate length, probability, random ratchets. PAT output fires at each pattern start |
| Entropy | Noise-driven sequencer: white/pink/brown/chaos noise, a lockable shift register loop, density, range, slewed random CV |
| Rhythm Composer | 808 / 909-style drum synth with 10 voices (BD SD CP CH OH LT HT RS CB CY), 808, 909, Dirt and LoFi kits, a 16-step grid and a trigger input |
| Voice 303 / Voice Poly | Analog-modeling mono voices with 7 models: Acid (303-style), Ladder (Moog-style), Scream (MS-20-style), Jove (Jupiter-8-style), Prophecy (Prophet-5-style poly-mod), SEM (Oberheim-style), Odyssey (ARP-style) |
| Titan | Dual wavetable bass synth for dubstep: 6 morphing tables, unison, sub, 4 filter types, tempo-synced wobble LFO to cutoff and table position, drive and compression |
| Bitbox | 8-bit sound chip voice: pulse 12.5/25/50%, 4-bit triangle, LFSR noise, arpeggios, vibrato, bit crushing, stepped volume envelopes |
| Bodies | Physical modeling: Karplus-Strong string and tube, modal bell, marimba, membrane and glass |
| Geiger | Geiger counter with real decay statistics (Poisson process), sources from background radiation to a reactor core, burst clustering, click audio, trigger and count-rate CV outs |
| Slope, Wavefold, VCF-Q | Serge-inspired rise/fall function generator, sine wavefolder and variable-Q filter |
| Mix Desk | 8 channels with sends to a tempo-synced tape delay and a plate reverb |
| Monitor | Limiter, scope, spectrum, and the analyser the AI listens through |
| Contour | Dual function generator (Maths-style): rise, fall, curve, cycle, attenuverters, SUM/INV, end-of-rise and end-of-cycle triggers |
| Swarm | Eight related LFOs from one rate, with rate and phase spread, six shapes and tempo sync |
| Workout | Eight-output clock brain: divide and multiply from 4 bars to 1/32, euclidean fills, chance, rotation |
| Grains | Granular processor: records any input, replays it as grains with position, size, density, pitch, spray, reverse, freeze and feedback |
| Marbles | Random gates (T1-T3) and voltages (X1-X3) with déjà vu looping, spread and bias, a quantized NOTE out and a CV quantizer |
| Toolbox | Four VCAs/attenuverters with CV, offset, sample and hold with slew, AND/OR/XOR logic, crossfader |
| Tape | Plays the timeline's audio clips on four tracks (T1-T4 and a mix out) |

Every panel wears a worn, scratched finish generated by `tools/make_panels.py` (PNG and WebP in `assets/panels/`).

## Timeline

The strip under the rack works like a DAW timeline.

* **Record** (● or R) captures everything you and the AI do: knob turns become automation lanes, and cables, added or removed modules, pattern edits, transport and the AI's narration become events. AI moves are cyan, yours are amber.
* **Play** (Space) restores the patch as it was when recording started and replays every move, with knobs and cables glowing as they change. Shift-drag in the ruler to set a loop.
* **Edit**: drag points and events to move them, drag points up and down to change values, double-click a lane to add a point, Alt-click or Delete to remove, drag a box to select several. The inspector in the toolbar edits the selected item's exact time and value. **＋ Action** inserts a knob move, cable, module, clock start/stop or marker at the playhead.
* **Audio clips**: drop audio files onto an audio track (or use ♫ Audio). Drag to move, drag the edges to trim, drag the white handles for fades, S splits at the playhead, Ctrl+D duplicates. Clips play through the Tape module, which you can patch anywhere.

Use **+ Add module** in the top bar to add as many extra sequencers, voices, mixers and utilities as you like, and the × on a panel to remove it. The Monitor has four inputs, so extra mixers can be patched in.

On a sequencer, the A–H buttons pick a pattern (it switches when the current one ends), SONG turns song mode on, and the PITCH/PROB/RATCH button picks what dragging a step edits. In the song chain, click an entry to double its repeats, Shift-click to change its pattern, Alt-click to remove it, and + to append the selected pattern.

Jack colours: silver is audio, orange is CV, green is clock/gate/note events (green only connects to green). Drag from a jack to another jack to patch, drag a plugged input away to unplug, double-click a jack to clear it. Drag knobs up and down (Shift for fine), double-click to reset.

## The AI performer

* **Reads the brief.** The action text sets the genre (acid, dubstep, drum and bass, techno, house, chiptune, ambient, noise, trap, experimental), the mode (design a patch, perform a set of a given length, or tweak what is playing) and the duration. The personality text sets traits such as aggression, chaos, calm, melodic and dark.
* **Patches visibly.** A glowing cursor travels to each jack and knob. Cables are carried across the rack and plugged in, knobs turn smoothly, sequencer steps and drum cells light up as they are written, and the log explains every move.
* **Listens.** Every 200 ms it measures loudness, spectral brightness, low end, rhythmic motion and an overall energy score from the master output, and compares them with its targets.
* **Learns.** It chooses among about 25 moves (filter sweeps, drive, drum mutes and fills, sequence mutations, wobble rate changes, modulation patches, layering voices in and out, delay throws and more), scores each one by how much closer it moved the sound to the target, and keeps a running value per move. Those values are saved in the browser and shown in the console, so it gets better at your rack over time.
* **Grows the rack.** It can add new modules while it works: an extra sequencer plus a voice for each new layer, and another mixer when every channel is taken. Ask for something "complex", "layered" or a "song" to get more layers. It writes patterns A–D (main, variation, stripped-back, fill) for each sequencer and chains them into a song.
* **Composes fresh lines.** Every melody, bass and acid line is built from a randomly chosen rhythm (euclidean, additive groupings like 3+3+2, call and response, syncopated, dotted, sparse, driving 16ths) and pitch idea (a short motif developed by inversion, transposition or reversal, a wandering line with leaps, arpeggios over a random chord loop, a contour shape, a melody against a pedal note), then checked against recent lines so it doesn't repeat itself. Each design picks one key for every layer. The log names the idea it used.
* **Listens back and critiques itself.** Every 60 seconds (adjustable) it records 6 seconds of the master and measures level, clipping, spectral balance, roughness (sensory dissonance), the key it hears versus the keys the sequencers use, and motion. It asks what works, what doesn't and what clashes, then corrects course and credits or blames the moves it made since the last listen. With the Claude brain, Claude judges it from a spectrogram image plus the measurements and patch state; otherwise a built-in critic does. The clip, the spectrogram and the verdict appear under "Listening back".
* **Performs.** For a set it builds an energy arc (intro, build, drop, break, build, peak, outro) across the requested length, switches sequencer patterns to match each section, writes new variations, adds layers, and keeps shaping the sound until the end, then fades out.
* **Claude brain (optional).** When the page is opened as a Claude artifact, "Claude plans" sends the brief, the module catalogue and the current patch to Claude, which returns the patch design and the set's sections as actions. The built-in performer then executes them and keeps listening and adjusting.
